구글 지도 API 키 설정

키는 이 브라우저에만 저장돼요

무료로 쓸 수 있나요?2025년 3월부터 월 $200 크레딧 대신 상품별 무료 사용량이 적용돼요. 지도 로드(Dynamic Maps)는 월 10,000회까지 무료라 개인 여행 일정표 용도로는 충분해요.
3분 만에 키 발급받기1. Google Cloud Console에서 새 프로젝트 생성
2. API 및 서비스 → 라이브러리에서 Maps JavaScript API 검색 후 사용
3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키 복사
과금을 0원으로 막는 법API 및 서비스 → Maps JavaScript API → 할당량에서 Map loads per day를 300으로 제한하세요. 한 달(31일)을 꽉 채워도 9,300회라 무료 한도를 넘지 않아요.

※ 코드 상단 DEFAULT_GOOGLE_MAPS_API_KEY 변수에 직접 넣어도 됩니다.
